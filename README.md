# 🎸 Ami Fossils

> A fan-made, vibe-coded virtual concert experience for Fossils listeners.

🔗 **Live Demo:** [ami-fossils.vercel.app](https://ami-fossils.vercel.app/)

## 🎵 About

I’m a Fossils fan and had some free time, so I decided to vibe-code a small virtual concert experience.

The idea was simple: instead of just playing a song, make it feel a little more like being at a Fossils concert. 🎸

This is a **personal, non-commercial fan project** made purely for fun and experimentation.

## ✨ Features

- 🎵 Local music player
- ▶️ Play / Pause / Next / Previous
- 🔀 Shuffle & Repeat
- 🎚️ Functional audio equalizer
- 💡 Concert-style moving lights
- 🕯️ Audience lighters
- 🎤 Rupam Islam's concert speech moments
- 👏 Clap & 📣 Cheer reactions
- 🎉 Poppers / celebration effects

## 🛠️ Tech

- HTML5
- CSS3
- Vanilla JavaScript
- HTML5 Audio
- Web Audio API
- Vercel

No backend. No database. Just a frontend experiment.
